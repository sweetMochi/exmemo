# Hannah's Motion Library（動態收藏）

> [!info] 資源
> 由 UI/UX 設計師 Hannah 整理的網頁動態效果收藏庫 · [網站連結](https://kittenjam-motion-library.vercel.app)

## 用途

收錄網路上常見、吸睛的動態效果，給設計師與開發者找動畫靈感，並了解怎麼實作。

## 內容

- **效果類型**：文字動畫、按鈕 hover、卡片進場動畫等
- **實作技術標籤**：CSS、GSAP、Canvas
- **可互動預覽**：部分效果可用滑鼠移動、捲動、拖曳來試
- **AI Prompt**：每個效果都有大圖預覽和完整 prompt，可一鍵複製「AI prompt」，內容說明外觀與實作方式

## 篩選方式

| 維度   | 說明                       |
| ---- | ------------------------ |
| 元件   | 按鈕、卡片／群組、文字…             |
| 時機   | hover、進場…                |
| 情境   | 使用情境                     |
| 組合篩選 | 例如「按鈕 × hover」、「卡片 × 進場」 |
| 排序   | 熱門、最新、編號                 |

另外可以依元件分組，也能收藏效果。
