# 帳戶改名後使用者資料夾路徑不一致

## 問題描述

Windows 帳戶由系統改名後，部分程式（例如 Autoruns）顯示或掃描的使用者資料夾仍是 `C:\Users\{舊使用者名稱}`，而不是目前登入使用者的資料夾，導致**無法顯示該使用者對應的設定或檔案**（例如 Startup 資料夾中的啟動捷徑）

> 實際案例：[[工作管理員啟動項目 Program 排查紀錄]]

## 確認是否一致

比對目前登入的使用者與使用者資料夾：

```powershell
whoami
$env:USERPROFILE
```

再與程式中顯示的路徑比對，若程式顯示的是舊名稱，即為不一致

## 原因

帳戶改名後，登錄中有兩個記錄使用者資料夾位置的機碼：

| 機碼                   | 用途                                       | 狀態                       |
| -------------------- | ---------------------------------------- | ------------------------ |
| `User Shell Folders` | Windows 實際使用的設定，通常寫成 `%USERPROFILE%\...` | 正確，指向新名稱                 |
| `Shell Folders`      | 給舊程式用的相容性快取，存的是完整路徑                      | 仍停留在 `C:\Users\{舊使用者名稱}` |

讀取 `Shell Folders` 的程式（例如 Autoruns）就會使用舊的路徑

```powershell
# 有輸出：Shell Folders 仍指向 olduser
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders" | Select-String olduser

# 沒有輸出：User Shell Folders 正常
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders" | Select-String olduser
```

## 修正 Shell Folders

```powershell
# 備份
reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders" "$env:USERPROFILE\ShellFolders_backup.reg"

# 將 C:\Users\olduser 改為 C:\Users\newuser
$key = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders'
(Get-ItemProperty $key).PSObject.Properties |
  Where-Object { $_.Name -notlike 'PS*' -and $_.Value -like 'C:\Users\olduser*' } |
  ForEach-Object {
    $new = $_.Value -replace '^C:\\Users\\olduser', 'C:\Users\newuser'
    Set-ItemProperty -Path $key -Name $_.Name -Value $new
    '{0} -> {1}' -f $_.Name, $new
  }
```

修改後登出再登入，重新開啟相關程式確認路徑已變為 `C:\Users\newuser\...`

## 處理舊的使用者資料夾

`C:\Users\{舊使用者名稱}` 不是已登記的使用者設定檔，也沒有對應的帳戶，可以移除。確認方式：

```powershell
# 只列出 C:\Users\newuser 表示 olduser 不是已登記的設定檔
Get-CimInstance Win32_UserProfile |
  Where-Object { -not $_.Special } |
  Select-Object LocalPath, SID, Loaded, LastUseTime

# LinkType 為空表示是一般資料夾，不是連結
Get-Item C:\Users\olduser -Force | Select-Object FullName, LinkType, Target
```

修正 Shell Folders 後，先改名觀察幾天，再刪除：

```powershell
# 以系統管理員身分執行
Rename-Item C:\Users\olduser olduser.old
```

若出現「存取被拒」，通常是資料夾仍被程式佔用，重新開機後再改名即可

確認沒有異常後刪除：

```powershell
Remove-Item C:\Users\olduser.old -Recurse -Force
```
